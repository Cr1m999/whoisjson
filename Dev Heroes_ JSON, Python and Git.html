Dev Heroes

JSON, Python and Git are not people, but today they are playable. Pick one, collect data, and squash the bugs before they catch you.

Move with WASD or the arrow keys, or press and drag on the arena. Guns auto-aim and fire at the nearest bug. Abilities: Space and Q. Dialogue: Enter or tap.

JSON, Python and Git walk into a repo. JSON brings the data, Python writes the script, and Git remembers who broke it.
